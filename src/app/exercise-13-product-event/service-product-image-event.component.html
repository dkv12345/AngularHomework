How this works (Exercise 13 Implementation):

  • Data is managed in ProductService using a structured array of JSON items.
  • The list component injects ProductService to retrieve the product collection.
  • Clicking the Details button invokes viewDetail(p), calling router.navigate(['service-product-image-event', p.ProductId]) to transition to the detail route with parameter binding.
